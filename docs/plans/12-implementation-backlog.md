# 개발 백로그와 인수 기준

**2026-10-04 관리자 전용 ESN 추가:** 이번 산출물은 [ESN 분석·분리 개발 계획](../esn-admin/README.md)과 진행표이며 구현·배포는 후속이다. 기존 KCP P0~P8과 E01~E26을 폐기하거나 완료로 처리하지 않는다. ESN은 기존 문의/일정/문서 코드를 재사용해 관리자 인증·고객 통합 조회부터 진행하고, 실제 계약/청구와 구매는 기존 업무의 선행 조건을 따른다. 단계별 상세 작업·상태는 [ESN 진행표](../esn-admin/05-progress.md) 한 곳에서 관리하고, 이 문서는 기존 백로그와의 연결을 기록한다.

## 모든 구현 항목의 완료 정의

요구사항이 코드·데이터·권한·화면·오류 처리에 반영되어야 한다. 금액·재고·예약은 서버와 DB에서 보호되고, 사용자에게 재시도·문의 경로가 있어야 한다. 필요한 테스트와 운영 로그가 존재하고 개발·staging·운영 설정의 차이가 설명되어야 한다. 문서와 실제 동작이 다르면 함께 갱신한다.

PR 템플릿은 문제와 결과, 요구 ID, 변경한 데이터/권한, 검증, 운영 영향, 롤백 방법을 포함한다. API 비밀·실제 고객 사진·주소·결제 원본을 첨부하지 않는다. 단순 코드 작성 종료를 출시 완료로 보고하지 않는다.

## 이관과 콘텐츠 준비 백로그

운영자가 제공할 파일은 승인 가격표, 서비스 범위, 직원 능력·근무일, SKU·원가·BOM·공급기간, 식품 라벨·로트 정책, 배송 요금, 실제 작업사진과 사용동의, 고객용 약관, 사업자와 인보이스 정보다. 합성 데이터로 개발한 내용과 실제 운영자료를 명확히 구별한다.

데이터 업로드 전 단위·중복·금액·GST·날짜를 검증한다. 이관 결과는 원본 건수·총금액·재고 총수량·중복 병합·실패행을 보고한다. 누락 자료를 임의 생성해 운영 DB에 채우지 않는다.
