## 과거 자료 보존

요청에 가격 버전 열을 추가하되 기존 행은 NULL 상태로 남긴다. 기존 요청의 조회와 새 분석은 이전 v2 정책으로 해석하고, 새 INSERT 기본값만 v3로 설정한다. 이후 요청의 가격 버전을 바꾸는 UPDATE는 차단한다. API는 클라이언트가 보낸 가격 정책을 채택하지 않는다.

기존 분석 v1/v2, 입력 스냅샷, 승인·서명·접수·예약, 감사 기록과 이미 동결된 메일/PDF를 다시 계산하거나 덮어쓰지 않는다. 진행 중 작업은 저장된 작업 가격 버전을 사용한다. 과거 v1의 DB 완료 호환 시험과 최신 AI runner가 오래된 prompt를 실행하는 것은 별개이며, 기존 runner의 오래된 분석 계약 처리 정책도 유지한다.

이미 서명된 요청에 따른 회사 예약 확정은 원본 소계·세금·총액을 그대로 사용한다. 이전 별도 회사 제안/고객 재동의 경로의 GST 계산·표기도 보존한다. 가격 v3와 예약 acknowledgment v2는 서로 다른 버전이다.

1. 가격 v3·이전 버전 계산/검증·요청 정책 고정을 추가한다.
