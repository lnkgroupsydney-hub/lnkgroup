# 서비스 마케팅과 성장 계획

## 시장 진입 방향

서비스 사업은 가까운 지역의 구체적인 수리·도장 수요를, 키트는 재방문 비용을 줄이려는 시공업체와 유지관리 담당자를 대상으로 한다. 같은 그룹에서 판매해도 구매 이유가 다르므로 광고·랜딩페이지·동의·성과를 사업별로 구분한다.

초기에는 실제 작업 가능한 Ermington 반경과 배차 능력에 집중한다. 2026-09-27 사용자 지도에 따라 KCP는 **Ermington 중심 10km**로 갱신했으며 Google Maps로 확인한 주변 suburb를 소개한다. Parramatta·Ryde 등 suburb 전체가 반경에 포함된다고 보장하지 않으며 경계 근처는 주소별로 확인한다. 정확한 회사 기준점은 확인 대기다. [KCP SEO·지역 개정](19-kcp-seo-content-and-service-area.md)을 현재 콘텐츠 기준으로 사용한다.

이 계획에 실제 시장 규모·검색량·CPC·경쟁사 매출 데이터는 포함되어 있지 않다. 키워드와 전환율은 검증할 가설이다. 광고 계정의 Keyword Planner, Search Console, CRM 실적을 확보한 후 수요와 입찰비를 보정한다.

## 확인한 비교 사례

[Jim's Handyman Sydney](https://jimshandyman.com.au/locations/new-south-wales/sydney-handyman/)는 Sydney 서비스 페이지를 운영한다. L&K는 브랜드 규모를 따라가기보다 좁은 지역의 구체적 작업 범위·가격 조건·사례를 명확히 하는 전략을 시험한다. 경쟁사의 예약 전환율이나 가격 경쟁력은 확인하지 않았다.

이 두 사례는 경쟁 전체를 대표하지 않는다. 착수 후 캐비넷·일반 페인팅·키트의 각 3개 실제 경쟁 사이트를 표본으로 추가 조사해 범위·견적 진입·응답 시간·신뢰 자료·배송 조건을 비교한다. 확인 전 경쟁사 단가를 L&K의 판매가격으로 쓰지 않는다.

## SEO 설계

서비스 카테고리 → 실제 제공하는 세부 작업 → 사례 → 견적 흐름을 연결한다. 초기 8개 서비스 상세는 고객 질문·포함/제외·작업 시간·가격 조건·현장 사진·관련 서비스를 고유하게 작성한다. 지역명만 바꾼 수십 페이지를 만들지 않는다. 실제 사례와 지역 차이가 있을 때 별도 지역 페이지를 추가한다. [Google 스팸 정책](https://developers.google.com/search/docs/essentials/spam-policies)

| 검색 의도 가설 | 연결 페이지 | 필요한 콘텐츠 |
| --- | --- | --- |
| handyman Ermington / small home repairs | 핸디맨 카테고리 | 작업 목록, 지역, 최소 방문 범위 |
| silicone resealing / flyscreen replacement | 개별 서비스 | 손상 예시, 포함 범위, 사진 제출 |
| interior painting quote | 내부 페인팅 | 측정·준비·제품·완료 과정 |
| cabinet painting Sydney | 캐비넷 페인팅 | 가능한 재질, 탈부착, 마감 사례 |
| custom paint touch up kit | 키트 상세 | 구성·색상·용량·제작·로고 승인 |

페이지별 title·description·H1·canonical·OG·sitemap을 관리한다. 구조화 데이터는 실제 정보만 넣고 LocalBusiness/Service/Product/Offer/Breadcrumb 등 페이지에 맞는 유형을 검토한다. 후기나 평점을 만들어 넣지 않으며 표시 자격과 검색 결과 노출은 별도다. 고객·견적·장바구니·검색 필터·관리자 페이지는 색인 정책을 제한한다.

Google Business Profile은 실제 사업 자격과 운영 장소를 기준으로 관리한다. 방문 서비스 사업자의 서비스 지역 설정을 사용하고 검색 노출을 늘리려고 가상 주소·중복 지역 프로필을 만들지 않는다. [Google 사업 프로필 지침](https://support.google.com/business/answer/3038177?hl=en)

## 채널별 운영

Google Search Ads는 A 출시와 거래 흐름 검증 후 지역·서비스별 소규모 캠페인으로 시작한다. 검색 의도가 높은 수리·도장 키워드를 우선하고 'jobs, salary, course, free, DIY' 등은 실제 검색어를 보고 제외한다. 광고의 위치 설정과 랜딩 주소 검증을 함께 사용한다. 광고 반경만으로 서비스 지역을 보장하지 않는다.

Meta·Instagram은 캐비넷 전후와 작업 과정 콘텐츠에 활용한다. 리타게팅은 동의와 플랫폼 정책에 맞춰 적용한다. 처음부터 대규모 예산을 쓰지 않고 유입→유효 문의→계약→기여이익을 확인한 뒤 증액한다.

B2B는 지역 부동산 관리회사·도장업체·유지보수업체 대상으로 샘플·작업보고서·재주문 편의를 제안한다. 무단 이메일 대량 수집·발송을 하지 않고 행사·소개·문의·동의 기반 접점을 쌓는다. 소개 프로그램은 혜택·조건을 명확히 하고 긍정 후기만 쓰는 대가로 보상하지 않는다.

고객 이메일은 시공 후 관리 가이드, 키트 사용법을 별도 관심군으로 운영한다. 견적 리마인더의 횟수·간격은 실제 고객 관계와 메시지 성격을 검토한다. 구독 결제는 초기 범위 밖이다.

## 콘텐츠 운영 캘린더

첫 달은 1주차 서비스 포함 범위와 사진 촬영법, 2주차 실리콘·방충망 실제 사례, 3주차 내부 페인팅 준비와 작업 중 생활 안내, 4주차 캐비넷 재도장 적합성 사례를 발행한다. 각 주에 사이트 사례 1건·짧은 영상 1건·FAQ 개선 1회를 목표로 한다. 실제 작업 사진이 없으면 도식으로 설명하되 실제 고객 사례처럼 표현하지 않는다.

키트 출시 시 구성·색상 코드·라벨 시안·사용법을 우선한다. 콘텐츠 책임자는 사실·사진 동의·브랜드 사용권을 확인하고 운영자가 질문에 답할 수 있는 범위만 게시한다.

## 광고 예산과 수익 기준

월 A$3,000의 **유료 매체 실험 예산 가정**: 검색광고 1,800, Meta 600, 키트 B2B 타깃 캠페인 300, 예비 300. 합계는 3,000이다. 미출시 상품 예산은 쓰지 않는다. 촬영·콘텐츠·대행 인건비·쿠폰·샘플·도구 비용은 별도다. 광고 플랫폼에서 지출 한도를 설정하고 실제 주당 작업 수용량을 초과해 문의를 사지 않는다.

계산 예시: 광고 클릭 1,000 × 유효 문의율 5% × 견적 발행률 80% × 수락률 35% × 완료율 90% = 예상 완료 12.6건. 매체비 1,800이면 예상 완료당 매체비는 약 A$142.86이다. 수치 모두 가정이며 광고 수익 예측 보장이 아니다. 목표 CAC를 비교할 때 별도 콘텐츠·대행비도 포함한다.

다른 단위경제 예시: GST 제외 매출 600 - 직접 노동 240 - 자재 80 - 이동 30 - 결제 12 - 재작업 충당 18 = 광고 전 기여이익 220. 목표 잔여 기여이익을 120으로 두면 총 고객획득비 한도는 100이다. 위 가정의 매체 CAC 142.86은 이미 한도를 넘으므로 광고 확대보다 전환·원가·가격 개선이 먼저다. 매출 대비 광고비 비율만으로 성공을 판단하지 않는다.

## 측정 사전

2026-09-27 사용자 설명상의 개발자 보상은 웹 유입으로 인정되는 매출의 5%이며 GST 포함 기준이다. 아래 사업 보고용 순매출과 계약상 정산대상매출을 별도 지표로 관리한다. 현재 전체 월매출 약 A$3,000과 앞의 광고 실험 예산 A$3,000은 서로 다른 값이며, 광고 예산은 승인된 지출이 아니다.

| 지표 | 정의 | 초기 판단 |
| --- | --- | --- |
| 유효 문의율 | 서비스·지역·연락처가 유효한 문의 / 관련 방문 | 4주 기준값 후 목표 설정 |
| 견적 수락률 | 수락 견적 / 발행 견적, 동일 발행 코호트 | 25~40% 시험 목표, 실제값 아님 |
| 서비스 CAC | 마케팅 비용 / 신규 고객의 완료 작업 수 | 작업 기여이익 한도 이내 |
| 구매 전환율 | 결제 완료 주문 / 해당 매장 방문 세션 | 1~3% 시험 목표, 실제값 아님 |
| 순매출 | 판매액 - 취소·환불, GST 별도 | 예약금 이중 계산 금지 |
| 웹 유입 정산대상매출 | 계약에서 인정한 웹 유입 거래의 금액, 사용자 설명상 GST 포함 | 환불·할인·입금 시점·재구매·귀속 규칙 미정 |
| 매출배분금 | 웹 유입 정산대상매출 × 5% | 최소 보수·지급일·수수료 자체의 GST 처리 미정 |
| 반복 구매율 | 기간 내 2회 이상 구매 고객 / 관찰 가능한 첫 구매 고객 | 키트 기준 |
| AI 검토율 | 사람 검토 건 / 사진 분석 건 | 정확도와 함께 판단, 낮음만 추구하지 않음 |

이벤트는 service_view, area_check_result, quote_submitted, quote_issued, quote_accepted, booking_confirmed, purchase, refund, repeat_purchase를 정의한다. 결제·수락·예약 확정 이벤트는 서버 기준으로 기록한다. order_id/event_id로 브라우저·서버 중복을 제거하고 원본 주소·사진·이메일을 분석 이벤트에 넣지 않는다. UTM과 유입 채널은 고객 동의·보관 정책에 맞게 CRM에 연결한다.

웹 유입 후 전화 계약·계좌이체, 사이트를 보고 바로 건 전화, 기존 고객의 온라인 신청, 재구매·추가 공사, 계약 종료 후 입금의 인정 범위를 계약에서 먼저 정의한다. 온라인 결제 여부만으로 웹 유입을 판정하지 않는다. 문의 출처와 근거를 견적·인보이스·입금·환불에 연결하고 출처 변경·정산 조정 이력을 남기는 방식을 제안한다. 미확인 출처를 자동 인정·제외하지 않고 검토 절차를 정한다. 상세 협의 항목은 [내부 계약 검토](16-revenue-share-contract-review.md)에 있다.

주간 회의에서는 유입이 부족한지, 문의가 무효인지, 견적 수락이 낮은지, 작업이 남는지부터 구분한다. 소량 데이터에서 한 주 수치로 캠페인을 단정하지 않는다. 재작업·분쟁·배송 사고가 증가하면 신규 고객 유입 확대를 멈추고 운영 원인을 해결한다.
