# 기존 프로젝트 분석

기준일 2026년 9월 25일. 사용자 제공 ChatGPT 프로젝트를 Codex의 연결된 대화 조회 기능으로 확인했다. 웹 URL 자체는 로그인 화면을 반환했으나 연결된 프로젝트에서 다음 대화를 읽을 수 있었다. 대화의 과거 AI 추천은 사용자 확정 사항과 구분했다.

## 확인한 자료

| ID | 자료 | 관찰한 내용 | 해석 한계 |
| --- | --- | --- | --- |
| P01 | [메인과 제품페이지 분리](https://chatgpt.com/c/6ab36ada-e3fc-83ec-90ae-5cdfa5b70c31) | 메인·상품 분리 요청, 서비스 카테고리와 개별 설명, SEO 의도 | 대화 및 이미지 시안이며 작동하는 코드 증거는 없음 |
| P02 | [Booking 지역 검증](https://chatgpt.com/c/6ab36f88-be84-83ec-9cb3-73fa6e93f569) | Ermington 반경 15km 외 자동예약 제한 요청 | 과거 답변에 직선·운전거리와 14~17km 예외 제안이 혼재 |
| P03 | [웹사이트 구축 비교](https://chatgpt.com/c/6ab3727a-6718-83ec-a451-fbd337cca011) | Next.js·Supabase와 웹 빌더 비교, 관리자와 결제 연동 추천 | 추천 내용 전체가 승인된 요구사항은 아님 |
| P04 | 현재 사용자 요청 및 ESN 답변 | 4개 사업, AI 추가견적, 수락·예약·인보이스, ERP·CRM | 세부 운영 정책은 신규 범위 |
| P05 | 현재 프로젝트 폴더 | 조사 시작 시 firebase-debug.log만 존재 | 다른 저장소나 실제 도메인 배포 존재 여부는 확인하지 않음 |

폴더에 Firebase 로그가 있다는 사실만으로 Firebase 기반 구현이 있다고 판단하지 않는다. 다른 PBC 프로젝트는 별개 사업 자료이므로 코드를 가져오거나 가격을 재사용하지 않았다. 이 프로젝트에서 조회된 대화 3개와 첨부 3개를 분석했으며, 조회되지 않은 대화·숨은 파일까지 확인했다고 주장하지 않는다.

## 이미지 시안에서 가져올 범위

| 시안 | 유지할 방향 | 수정할 방향 |
| --- | --- | --- |
| [메인 화면](../reference-assets/main-page.png) | 단순한 내비게이션, 서비스 카테고리 카드 | Products를 서비스와 구별. 거대한 중앙 로고 대신 모바일 주요 버튼 우선 |
| [핸디맨 화면](../reference-assets/handyman-page.png) | 작업별 카드와 Learn More | 전부 출시 서비스로 확정하지 않음. 서비스 가능 여부·자격·원가 확인 후 활성화 |
| [상품 화면](../reference-assets/product.png) | 키트·스티커·색상·프로 키트 분류 | SKU·옵션·재고·제작 리드타임·장바구니가 추가로 필요 |

메인 시안의 Kitchen Cabinet 설명은 캐비넷 제작·설치를 암시한다. 현재 요청은 **캐비넷 페인팅**이므로 명칭과 설명을 Cabinet Painting으로 수정한다. 새 캐비넷 제작, 설치, 구조 변경은 계약에 추가되지 않는 한 범위 밖이다. 시안에 보이는 lkgroup.com은 소유가 확인된 운영 도메인이 아니다.

핸디맨 시안은 타일, 실리콘, 외부 세척, 가구, 문, 유리, 바닥, 방충망, 샤워스크린, 벽걸이 등 11개 항목을 제시한다. 유리·샤워스크린·방수 관련 작업은 적절한 자격과 작업 범위를 확인한 뒤 판매한다. 화면에 있다는 이유로 자동 견적 대상으로 삼지 않는다.

상품 시안의 30병·50병 세트와 30색 프로 키트는 **시안상의 후보 구성**이다. 빈 병인지 페인트가 채워진 제품인지, 색상 조합, 용량, 공급원, MOQ와 제작 기간을 먼저 확정한다. 실제 사진과 상표 사용권도 필요하다.
