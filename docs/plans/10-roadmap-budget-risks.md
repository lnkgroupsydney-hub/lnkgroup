**2026-10-04 ESN 분리 기획:** [관리자 ESN 로드맵](../esn-admin/04-roadmap-and-acceptance.md)의 인증 → 고객 통합 조회 → 운영 청구/구매 → 운영 인수 순서로 범위를 나눈다. 이번은 기획 완료이며 신규 기능 개발 완료가 아니다. 실제 도메인·관리자 범위·구매 의미·가격/계약/자원·결제 조건이 미정이고 독립 앱/배포는 대안이므로 ESN 납기·비용을 아직 확정하지 않는다. 아래 최초 일정·전체 사업 공수는 ESN 추가 견적이나 회사 승인 비용으로 전용하지 않는다. [결정·의존성](../esn-admin/05-progress.md)을 확인한다.

## 웹 매출배분 제안과 비용 부담

2026-09-27 사용자 최종 설명에 따르면 제안된 보상은 **웹 유입으로 인정되는 매출의 5%**이며 GST 포함 A$1,100 결제의 배분금은 A$55다. 그룹 전체 매출을 적용하는 전제로 계산하지 않는다. 현재 월매출 약 A$3,000은 사용자 설명이고 웹 유입 인정액은 미확인이다. 전체가 정산 대상이어야 월 A$150이며 실제 보수는 아직 산정할 수 없다.

개발용 AI 비용은 개발자가 부담하고, 도메인·서버·사진분석 API 등 회사 운영 실비는 회사에 청구한다는 사용자 방침이다. 상대방과의 비용·지급 서면 합의, 최소 보수·기간·해지·IP·웹 귀속 규칙은 미정이다. 아래 구축비·운영비는 기존 예산 가정이며 이 매출배분 제안에 포함되거나 면제된 금액으로 해석하지 않는다.

개발·유지관리 보수와 웹 매출 성과 보상을 구분하고 단계별 투자 한도를 정하는 안을 제안한다. 상세 조건과 회수 예시는 [내부 계약 검토](16-revenue-share-contract-review.md)에 기록한다. 첫 단계의 작은 출시와 전체 ERP·AI·자동화 범위는 별도로 산정한다.

## 일정 기준

2026-09-27 사용자 요청에 따른 우선 제작 일정은 **메인 3일 → Cabinet 약 1주 → Coatly 기반 회사 관리 웹**이다. [실행 TODO](15-home-cabinet-admin-todo.md)를 우선 참조한다. 관리 웹 기간은 재사용 범위 확인 후 산정하며, 아래 18~24주는 쇼핑몰·AI·김치·ERP 확장을 포함한 기존 전체 범위의 추정이다.

아래는 요구 확정 전의 계획 추정이다. 시작일이 정해지지 않았으므로 W1을 착수 주로 둔다. 핵심 개발자 1명과 파트타임 개발·QA 지원, 디자인·PM·운영 담당의 지속 참여를 가정한다. 팀의 총 실투입 45~60시간/주가 유지되고 의사결정·콘텐츠가 제때 제공되면 **18~24주**를 전체 계획 범위로 잡는다. 1인 전담이 모든 역할을 맡고 주 30시간을 실제 개발에 쓰면 약 30~44주와 외부 대기 시간을 예상한다.

| 단계 | 목표 구간 | 공수 범위 | 출시 결과와 선행 조건 |
| --- | --- | --- | --- |
| 준비 | W1~W2 | 90~130h | 사업 규칙·원가·범위·디자인 확정 |
| A 서비스 | W3~W8 | 280~420h | 홈페이지·수동/규칙 견적·예약·고객·청구 |
| B 키트 | W9~W12 | 180~260h | 상품·재고·BOM·결제·배송·환불 |
| C 확장 | W13~W16 | 240~360h | AI 검토·김치·사업 보고·핵심 한국어 |
| 통합 안정화 | W17~W18 | 60~100h | 복구·보안·교육·전체 UAT·인수 |
| 합계 | 기본 18주 + 완충 최대 6주 | **850~1,270h** | 외부 승인·운영 준비에 따라 조정 |

표의 공수는 개발뿐 아니라 설계·PM·디자인·QA·교육을 포함한 총합이다. 완충 6주는 기본 기간에 대한 일정 여유이며 별도로 6주 인건비를 무조건 가산하지 않는다. A와 B의 출시 전에도 해당 기능의 필수 QA를 완료하며 마지막 안정화까지 테스트를 미루지 않는다.

## 주요 의존성

서비스 단가·자격 → 견적 승인 → 예약금 조건 → 결제·인보이스가 핵심 경로다. 키트 구성·공급·배송 프로필 → 재고·세금 → 구매가 이어진다. 김치는 제조·라벨·배송 검증이 완료되어야 출시할 수 있다. AI는 실제 사례·전문가 평가가 부족하면 기능은 검토 지원까지 제공하고 자동확정 일정은 재산정한다.

주 1회 30~45분 의사결정 회의, 2주마다 시연을 제안한다. 대표는 범위·가격·정책 최종 결정, 운영자는 프로세스·UAT, 개발 리드는 기술·보안·배포, 회계는 세금·청구, 식품 책임자는 식품 출시를 맡는다. 한 사람이 여러 역할을 맡더라도 각 승인 역할을 기록한다.

## 구축비 가정

실제 업체 견적이나 시장 단가 조사 결과가 아니라 **예산 논의를 위한 혼합 시간당 A$100~140 가정**이다. GST·외부 촬영·식품 검사·법률·상표·생산설비·운영인건비·광고비는 별도다. 개발자를 직접 고용하거나 AI를 활용하는 경우에도 검토·테스트·운영 준비 시간이 사라지지는 않는다.

| 범위 | 공수 | 가정 비용 GST 제외 |
| --- | --- | --- |
| 준비 + A | 370~550h | A$37,000~77,000 |
| B 추가 | 180~260h | A$18,000~36,400 |
| C 추가 | 240~360h | A$24,000~50,400 |
| 통합 안정화 | 60~100h | A$6,000~14,000 |
| 전체 기본 | 850~1,270h | **A$85,000~177,800** |
| 20% 예비비 포함 | 기본 비용 × 1.2 | **A$102,000~213,360** |

예산이 부족하면 A의 출시와 안정화에 우선 배정하고 B·C를 나눈다. 권한·금액·예약 중복 방지 검증을 제거해 비용을 맞추지 않는다. 고급 회계 연동·구독·여러 법인·추가 언어·전국 배송은 변경 요청으로 산정한다. 고정가 계약은 준비 단계에서 승인된 범위와 제외 사항을 기준으로 다시 견적한다.
