## 검사 중 해결한 사항

KCP 검증기가 과거 `10 km radius` 본문을 요구해 SSR 검사가 실패했다. 최신 승인된 홈의 거리 숫자 제거에 맞춰 Ermington·Inner West Sydney·인근/확장 지역 안내·주소별 가용성 확인·10km 미노출을 검사하도록 수정했다. 중앙 21개 지역의 정확한 순서·세 목록·지도·KCP 요약 링크·FAQ 검사는 유지했고 전체 16개를 다시 통과했다.

분리된 환경에는 `.env`를 복사하지 않았다. 첫 관리자 404와 홈의 견적 진입 실패는 UI 활성화 플래그 누락이었다. 실제 DB/Auth URL 없이 `STAFF_ADMIN_AUTH_ENABLED=true`, `QUOTE_LIVE_ENABLED=true`로 로컬 서버만 재시작해 관리자 3개와 홈 12개를 통과했다.

견적 작업의 마지막 QA에서 인증/revision 변경 뒤 취소된 달력 조회가 재시작하지 않는 경우와 pending review 재시도 뒤 서명 입력 게이트가 닫힌 경우를 수정했다. 최신 두 파일을 동기화한 production build에서 날짜·review 동일 payload 재시도와 입력/단계 보존을 다시 확인했다.

## 범위와 제한

브라우저 upstream은 별도 `127.0.0.1:3043`, 견적/관리자 fixture는 3044/3045였다. 로컬 PGlite와 합성 제공자를 사용하고 외부 요청을 차단했다. 회사 DB·실제 고객 인증 이메일·Google·AI·메일을 호출하지 않았다. 회사 운영 배포 명령·새 서비스 연결·DB migration·의존성 변경·색인 활성화는 수행하지 않았다. 실물 기기·Safari·실제 브라우저 확대·정량 GPU 성능·운영 인수로 확대해석하지 않는다.
