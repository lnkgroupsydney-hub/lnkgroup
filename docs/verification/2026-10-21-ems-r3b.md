## native modal dialog contract — lead 결정 B

기존 취소·관리자 dialog와 같은 native `showModal()` 계약을 유지한다. 이번 단계에서 `modalFocus`는 기준본과 바이트 동일하다.

1. 열릴 때 H2에 포커스가 있고 `open`·`:modal`이 true다.
2. 활성·표시·Tab 도달 가능한 control n개에 대해 Tab n+2회, Shift+Tab n+2회를 누른다. 모든 control에 적어도 한 번 도달해야 한다.
3. 매번 dialog 안이거나 BODY이면서 `document.hasFocus() === false`인 브라우저 UI 이동이어야 한다. 바깥 페이지 요소의 포커스는 실패한다.
4. 바깥 활성 버튼의 실제 노출 좌표를 클릭해도 click 수신 0·URL·본문·업무 상태 불변이어야 한다.
5. busy가 아닐 때 Escape로 닫히고 같은 trigger로 포커스가 돌아와야 한다.

**최종 실제 관측:** control 3개 모두 [0, 1, 2] 도달, 키 입력 10회, 브라우저 UI 이동 2회·바깥 페이지 요소 포커스 0회. 바깥 버튼 click 0회·화면/업무 불변·Escape trigger 복귀를 확인했다.

전체 페이지 screenshot 직전 blur는 skip link의 우연한 표시를 피하기 위한 처리이며 포커스·키보드 단언 뒤에만 수행한다.
