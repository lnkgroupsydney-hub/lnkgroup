[사진/예약 검증](../verification/2026-10-04-private-photos-mobile-booking.md)의 229개, [접근 검증](../verification/2026-10-04-esn-admin-access.md), [온보딩 검증](../verification/2026-10-04-staff-admin-onboarding.md)의 전체 294개·QR 수정 관리자 67개는 당시 결과다. 회사 세션 검사·실제 앱 로그인·사용자 영구 비밀번호 변경은 확인했다. 10월 4일 이메일 코드 방식은 당시 전체 업무 검사 **320/320**·lint·타입·격리 production 빌드를 통과했다. 사용자 승인 후 이메일 검증 SQL 적용 성공·service RPC 응답·anon 차단을 확인했고, 이메일 모드를 켠 로컬 앱의 기존 사용자 세션으로 확인 화면까지 도달했다. 실제 발송 요청 후 Resend 수락·서버 `sent`와 6자리 입력·10분 만료/60초 재발송 카운트를 확인했다. 사용자의 이메일 수신·코드 인증 완료 후 실제 DB의 활성 검증 1개·코드 해시 제거를 확인했다. 새 관리자 탭에서 문의 7건·서명 데모 요청 4건과 Calendar/Gmail 영역이 열렸으며 콘솔 오류·경고는 없었다. 기존 서명 요청 상세의 비공개 사진 로드와 새로고침 후 인증·업무 복원도 확인했다. PDF 본문은 당시 브라우저 다운로드 제한으로 미확인이었고 10월 6일 아래 읽기 확인으로 보완했다. 추가 관리자·로그아웃/회수 등 전체 인수는 남아 있다. [최신 이메일 검증](../verification/2026-10-04-staff-email-verification.md)에서 코드 검사와 회사 실연동을 구분한다.

## 2026-10-06 구현·검증과 회사 적용

[오늘 계획](06-2026-10-06-implementation-plan.md)에 따라 자기 세션 관리와 고객 통합 조회 코드를 구현했다. 전체 업무 검사 **359/359**·lint·타입·production 빌드가 통과했다. 검토에서 발견한 세션 정리 재시도 차단, 연결 원본 검색 누락, 감사의 개인정보 복제, 새 고객 선택 후 이전 연결 확인 유지 문제를 수정했다. 고객 생성/연결의 응답 유실·중복·revision 충돌과 감사 실패 rollback, 인가·최소 DB 권한·원본 보존을 합성으로 확인했다.

실제 직원 로그인·이메일 확인 후 기존 견적/서명 약관 PDF 두 개를 다운로드해 각 2페이지 본문을 읽고 총 4페이지 렌더의 참조번호·데모 표시·서명·가독성을 확인했다. 비공개 사진 640×480 로드도 확인했다. 회사 DB 기존 21테이블/7 RPC 읽기 검사 통과와 Dashboard 새로고침 후 Healthy 표시를 확인했으며 새 schema 적용 검증으로 확대하지 않는다.

**회사 적용 확인:** `20261006102454_staff_session_security.sql`과 `20261006102621_esn_customers.sql`의 Supabase 편집기가 최종 확인에서 성공 결과로 전환된 것을 확인했다. 새 3테이블·4함수의 service/anon 읽기 전용 권한 검사 14/14, 실제 관리자 고객 0건·미연결 원본 7건·현재 세션/다른 세션 0건 읽기를 확인했다. 합성 UI의 생성·연결/해제·응답 유실 재시도·충돌·세션 부분 실패·401·320/390px·키보드 검증도 완료했다. 실제 고객 생성/연결·실제 다른 세션 종료는 수행하지 않았다. PGlite의 단일 연결/직렬화 검사를 실제 다중 DB 연결 경합 통과로 표시하지 않는다. [당일 검증 기록](../verification/2026-10-06-esn-customers-and-sessions.md)을 실제 실행 결과에 따라 갱신한다.
